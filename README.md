# Sandeep M — Cybersecurity & Cloud Security Portfolio

A responsive, black-and-white portfolio designed as a no-long-scroll, section-switching website. Use the top navigation or bottom arrow controls to swap between Home, About, Experience, Projects, Skills, Research, and Contact. Arrow keys also switch sections on desktop.

## Files
- `index.html` — content and section structure
- `style.css` — responsive monochrome styling
- `script.js` — section switching, keyboard controls, and mobile navigation
- `assets/profile.png` — portrait image
- `assets/Sandeep_M_Resume.pdf` — resume download

## Preview locally
Open `index.html` in a browser. No build tools, backend, or package installation are required.

## Before publishing
1. Replace the generic LinkedIn and GitHub links with your real profile URLs.
2. Verify all dates, certification statuses, research publication status, and project descriptions.
3. Ensure you are comfortable making the included resume and email publicly accessible.
4. Never publish confidential internship/client information, credentials, internal infrastructure details, or NDA-covered screenshots.

## Free GitHub Pages hosting
1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder (including the `assets` folder) to the repository root.
3. Go to repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and `/(root)`, then Save.
5. When deployment completes, visit `https://YOUR-USERNAME.github.io`.
